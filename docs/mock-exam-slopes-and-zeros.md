# Part I. Multiple Choice (1 point each)

**1.** Which table of values shows a **linear** function?

**2.** A linear function always has a constant _______.

**3.** Slope is the ratio of the _______ change to the _______ change between two points.
A. run, rise  B. x, y  C. vertical, horizontal  D. horizontal, vertical

**4.** Slope is denoted by the letter _______.

**5.** Using the points (1, −1) and (3, 2), the slope is _______.
A. 2/3  B. 3/2  C. −3/2  D. 1/2

**6.** A line that goes **up** as you read from left to right has a _______ slope.

**7.** A straight vertical line has a slope that is _______.
A. 0  B. 1  C. undefined  D. negative

**8.** A flat horizontal line has a slope of _______.
A. 0  B. undefined  C. 1  D. −1

**9.** In f(x) = mx + b, the value of **b** is the _______.
A. slope  B. y-intercept  C. zero  D. x-intercept

**10.** In f(x) = −3x + 5, the slope is _______.
A. 5  B. −3  C. 3  D. −5

**11.** In standard form Ax + By = C, the slope is _______.
A. A/B  B. −A/B  C. C/B  D. −B/A

**12.** For 2x + 4y = 8, the slope is _______.
A. 2  B. −2  C. 1/2  D. −1/2

**13.** The **zero** of a function is _______.
A. the y-value where the line crosses the y-axis
B. the x-value that makes the output equal to 0

**14.** If a line crosses the x-axis at (4, 0), then _______.
A. the zero is 4, and the x-intercept is the point (4, 0)

D. the zero is 0

**15.** Given the table below, the zero is _______.

| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|

**16.** Using the same table as item 15, the slope is _______.

A. −8  B. −4  C. 4  D. 8

**18.** Mika has ₱150 and spends ₱30 each day. After how many days will she have ₱0 left?

## Part II. Problem Solving

**1.** rise = 13 − 5 = 8; run = 6 − 2 = 4; **m = 8/4 = 2**

**2.** rise = −2 − 4 = −6; run = 1 − (−3) = 4; m = −6/4 = **−3/2**

**3.** Δx = 2 each step, Δf(x) = −6 each step; **m = −6/2 = −3**

**4.** A = 3, B = −6 → m = −A/B = −3/(−6) = **1/2**
*(check: −6y = −3x + 12 → y = ½x − 2)*

**5.** 0 = 5x + 15 → 5x = −15 → **x = −3**

**6.** 0 = −2x + 7 → 2x = 7 → **x = 7/2** (or 3.5)

**7.** From item 3, m = −3. Using (1, 11): 11 = −3(1) + b → **b = 14**
So f(x) = −3x + 14. Set to 0: 0 = −3x + 14 → 3x = 14 → **x = 14/3**
*(check: −3(14/3) + 14 = −14 + 14 = 0 ✓)*

**8.** Change in f(x): 5 − 2 = 3, 8 − 5 = 3, 11 − 8 = 3 → **+3, +3, +3 → constant, so YES it
is linear.** Slope = 3/1 = **3**.

**9.** (a) m = rise/run = **2/(−3) = −2/3**
(b) **Negative slope** — the line goes **down** as you read from left to right.

**10.** (a) **f(x) = −25x + 200**
(b) Slope = **−25**. It means the tank loses 25 litres every hour.
(c) 0 = −25x + 200 → 25x = 200 → **x = 8 hours**

## Part III. Essay — marking guide

Award up to 8 points. Credit the ideas listed; do not require verbatim wording.

**1.** Should state: slope measures steepness / it is the ratio of vertical change to
horizontal change / denoted m. Then:
- **Graph:** choose two points on grid corners, count rise (up/down) and run (across),
  divide rise by run.
- **Table:** divide the change in f(x) by the change in x between any two columns
  (or use (y₂ − y₁)/(x₂ − x₁)).
- **Equation:** in slope-intercept form f(x) = mx + b, the slope is the number m
  multiplied by x; in standard form Ax + By = C, the slope is −A/B.

**2.** Should state: the **zero is an x-value**, while the **x-intercept is a point**.
Example: a line crossing the x-axis at (4, 0) has x-intercept (4, 0) and zero x = 4.
Credit the explicit warning: the answer is "x = 4", not "(4, 0)".

**3.** Should state: a function is linear when equal changes in x always produce equal
changes in f(x). Include one constant-change table (e.g. +2, +2, +2) and one
changing-change table (e.g. +1, +2, +3), identifying which is linear.

**4.** Should state: standard form is Ax + By = C, with x and y on the same side.
Then show rearranging to slope-intercept form, or state the slope is **−A/B**.
Credit a worked example such as 2x + 4y = 8 → m = −1/2.

**5.** Should describe: (1) find the slope from two columns; (2) substitute one point into
f(x) = mx + b and solve for b; (3) write the full equation; (4) set f(x) = 0 and solve for x.
Credit a mention that the same zero can also be found by "walking" from a known row using
the slope.
